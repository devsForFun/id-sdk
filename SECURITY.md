# Security Policy

Please **do not** open public issues for security vulnerabilities.

Report them privately via GitHub's ["Report a vulnerability"](https://github.com/devsForFun/id-sdk/security/advisories/new)
form for this repository. We'll acknowledge within a few days.

Issues affecting the devsforfun ID service itself (rather than this client
library) should also go through the same private channel; we'll route them.

Supported versions: the latest published minor.
